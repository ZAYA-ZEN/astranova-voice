# Astra Nova Voice HUB — ไมค์ตามระยะ ใช้ได้ทุกเซิฟ + ร้านขายแอดออน 69 บาท

Copyright (c) 2026 ZAYA (ซายะ) สงวนลิขสิทธิ์ทั้งหมด — อ่าน [LICENSE](LICENSE)

แยกจาก Astra Nova Voice ตัวเดิม (ตัวเดิมยังใช้ได้ตามปกติ) ตัวนี้ฝากไว้บน Render **เครื่องเดียว ใช้ได้หลายเซิฟพร้อมกัน**

```
เซิฟ A (คีย์ 1) ─┐
เซิฟ B (คีย์ 1) ─┼─> [HUB บน Render: แยกห้องตามคีย์+เซิฟ] <── แอปผู้เล่น (ใส่ชื่อ/รหัสครั้งเดียว ระบบหาเซิฟให้เอง)
โลกเพื่อน (คีย์ 2)┘            │
                              └─ หน้าร้าน / ตรวจสลิป / ดาวน์โหลดแอดออนที่ฝังคีย์แล้ว
```

## หน้าเว็บ
| ลิงก์ | ใช้ทำอะไร |
|---|---|
| `/` | **หน้าร้าน**: ชื่อ Discord ให้ลูกค้าแอด (optius_z), QR ทรูมันนี่ + พร้อมเพย์ (ยอด 69), วิธีซื้อ, ข้อห้ามลิขสิทธิ์ |
| `/my` | **ศูนย์ผู้ซื้อ**: ใส่คีย์ → ดาวน์โหลดแอดออนแบบเซิฟ/โลก (ฝังคีย์แล้ว), วิธีติดตั้ง, ลิงก์แอป, ข้อห้ามลิขสิทธิ์ |
| `/admin` | **หลังร้าน**: ออกคีย์ให้ลูกค้า (ได้ข้อความพร้อมส่งทาง Discord), เช็กคีย์, ดูเซิฟที่ออนไลน์ |
| `/app/` | เว็บแอปคุยเสียง (iPhone / ทุกเครื่อง) |
| `/license` | สัญญาอนุญาตฉบับเต็ม |

## การขาย
1. ลูกค้าโอน 69 บาทตาม QR แล้วแอด Discord **optius_z** ส่งสลิปมา
2. ผู้ขายตรวจยอดเข้าเอง แล้วเข้า `/admin` → **ออกคีย์ใหม่** (ใส่หมายเหตุชื่อลูกค้า)
3. กดคัดลอกข้อความ (คีย์ + ลิงก์ศูนย์ผู้ซื้อ) ส่งให้ลูกค้าในแชท

## ตั้งค่าบน Render (Environment)
- `ADMIN_PASSWORD` → รหัสเข้า `/admin` (ตั้งเอง)
- `LICENSE_SECRET` → สร้างให้อัตโนมัติ **จดเก็บไว้ ห้ามเปลี่ยน/ลบ** (ถ้าเปลี่ยน คีย์ที่ขายไปแล้วใช้ไม่ได้ทั้งหมด)
- `MAX_SERVERS_PER_KEY` → คีย์ 1 อันใช้ได้กี่เซิฟพร้อมกัน (ค่าเริ่มต้น 3)
- `REVOKED_KEYS` → ระงับคีย์ที่ถูกแชร์ (คั่นด้วยจุลภาค)
- `CONTACT_NAME` → ชื่อ Discord ที่โชว์ (ค่าเริ่มต้น optius_z)

## วิธีติดตั้งของผู้ซื้อ (อยู่ในหน้าดาวน์โหลดด้วย)
- **เซิฟเช่า/BDS**: ลง `.mcaddon` แบบเซิฟ → เปิด Beta APIs → เพิ่ม `@minecraft/server-net` ใน `permissions.json` → รีสตาร์ท
- **โลกธรรมดา**: ลงแบบโลก → เปิดสูตรโกง + ปิด Require Encrypted Websockets →
  เจ้าของโลกเปิดแอป **Windows/Android** เครื่องเดียวกับเกม → ฉันเป็นเจ้าของโลก → **เปิดตัวเชื่อมในเครื่องนี้** → พิมพ์ `/wsserver localhost:19140`
  (คีย์อ่านจากแพ็กในโลกเอง ไม่ต้องพิมพ์ • พิมพ์ `/wsserver wss://...` ตรงไปที่ Render ใช้ไม่ได้ เพราะเกมไม่รองรับการเชื่อมต่อแบบเข้ารหัส)
- **ผู้เล่น**: แอปเดิม (APK/EXE/IPA) ใช้ได้เลย กด ⚙ เปลี่ยนเซิร์ฟเวอร์ → ใส่ลิงก์ HUB • หรือเปิด `<ลิงก์ HUB>/app/`

## ข้อควรรู้
- Render ฟรี: bandwidth ~100GB/เดือน ใช้ร่วมกันทุกเซิฟที่ซื้อ ถ้าขายได้เยอะควรอัปเป็นแพ็กเกจ Starter
- Render ฟรีหลับเมื่อไม่มีคนใช้ 15 นาที เปิดเว็บครั้งแรกรอ ~30 วินาที
- ประวัติคีย์ในหลังร้านหายเมื่อรีสตาร์ท แต่คีย์ยังใช้ได้ตลอด (ตรวจด้วยลายเซ็น)
