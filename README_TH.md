# Astra Nova Voice HUB — ไมค์ตามระยะ ใช้ได้ทุกเซิฟ + ร้านขายแอดออน 69 บาท

Copyright (c) 2026 ZAYA (ซายะ) สงวนลิขสิทธิ์ทั้งหมด — อ่าน [LICENSE](LICENSE)

แยกจาก Astra Nova Voice ตัวเดิม (ตัวเดิมยังใช้ได้ตามปกติ) ตัวนี้ฝากไว้บน Render **เครื่องเดียว ใช้ได้หลายเซิฟพร้อมกัน**

```
เซิฟ A (คีย์ 1) ─┐
เซิฟ B (คีย์ 1) ─┼─> [HUB บน Render: แยกห้องตามคีย์+เซิฟ] <── แอปผู้เล่น (ใส่ชื่อ/รหัสครั้งเดียว ระบบหาเซิฟให้เอง)
โลกเพื่อน (คีย์ 2)┘            │
                              └─ หน้าร้าน / ตรวจสลิป / ดาวน์โหลดแอดออนที่ฝังคีย์แล้ว
```

## หน้าเว็บ
| ลิงก์ | ใช้ทำอะไร |
|---|---|
| `/` | **หน้าร้าน**: ชื่อ Discord ให้ลูกค้าแอดเพื่อน (optius_z), QR ทรูมันนี่ + พร้อมเพย์ (ใส่ยอด 69 ให้แล้ว), ส่งสลิป, ข้อห้ามลิขสิทธิ์, ติ๊กยอมรับก่อนซื้อ |
| `/my` (หรือ `/dl`) | **ศูนย์ผู้ซื้อ** (เว็บแยกสำหรับคนซื้อแล้ว): ใส่คีย์ → ดาวน์โหลด: คีย์, แอดออนแบบเซิฟ/โลก (ฝังคีย์แล้ว), วิธีติดตั้ง, ลิงก์แอป, ข้อห้ามลิขสิทธิ์ |
| `/admin` | หลังร้าน: อนุมัติ/ปฏิเสธสลิป, ดูยอดขาย, สร้างคีย์แจก, หาคีย์จากเลขสลิป, ดูเซิฟที่ออนไลน์ |
| `/app/` | เว็บแอปคุยเสียง (iPhone / ทุกเครื่อง) |
| `/license` | สัญญาอนุญาตฉบับเต็ม |

## ขั้นตั้งค่า (ทำครั้งเดียว)
1. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub repo **ใหม่** (เช่น `astranova-hub`)
2. Render → **New → Blueprint** → เลือก repo นี้ → ระบบสร้าง `astranova-hub` ให้ (Singapore)
3. หน้า Environment ของ Render:
   - `LICENSE_SECRET` สร้างให้อัตโนมัติ → **จดเก็บไว้ ห้ามเปลี่ยน/ลบ** (ถ้าเปลี่ยน คีย์ที่ขายไปแล้วใช้ไม่ได้ทั้งหมด)
   - `ADMIN_PASSWORD` สร้างให้อัตโนมัติ → ใช้เข้า `/admin`
   - `EASYSLIP_API_KEY` (ไม่บังคับ) → สมัคร easyslip.com เพื่อให้ตรวจสลิปอัตโนมัติ
   - `DISCORD_WEBHOOK` (ไม่บังคับ) → แจ้งเตือนเข้า Discord ทุกครั้งที่มีคนซื้อ/ส่งสลิป
   - `CONTACT_NAME` (ไม่บังคับ) → ชื่อ Discord ที่ให้ลูกค้าแอดเพื่อน (ตั้งไว้ optius_z แล้ว)

## การตรวจสลิป
- **มี `EASYSLIP_API_KEY`**: ตรวจอัตโนมัติทั้งสลิปธนาคาร (พร้อมเพย์) และทรูมันนี่ วอลเล็ท ตรวจว่า
  ✔ เป็นสลิปจริงจากธนาคาร ✔ ผู้รับเป็นพีรพัฒน์ (ชื่อ หรือเบอร์ลงท้าย 9203) ✔ ยอด ≥ 69 บาท ✔ ไม่เก่าเกิน 48 ชม. ✔ สลิปซ้ำ
  ผ่าน → ได้คีย์ทันที • สลิปเดิมส่งซ้ำ → ได้คีย์เดิม (ไม่มีคีย์ใหม่งอก) • ระบบตรวจล่ม/โควตาหมด → ส่งเข้าหลังร้านให้ตรวจเอง
- **ไม่มี API**: ทุกสลิปเข้า `/admin` ให้กดอนุมัติเอง ลูกค้าเปิดหน้าค้างไว้ คีย์จะเด้งขึ้นเองเมื่ออนุมัติ

## คีย์ไลเซนส์
- รูปแบบ `ANV-XXXX-XXXX-XXXX` ตรวจด้วยลายเซ็น ไม่ต้องใช้ฐานข้อมูล (Render ฟรีลบไฟล์ทุกครั้งที่รีสตาร์ท ก็ไม่เป็นไร)
- คีย์เดียวใช้ได้ **3 เซิฟพร้อมกัน** (ปรับที่ `MAX_SERVERS_PER_KEY`)
- ระงับคีย์ที่ถูกแชร์: ใส่คีย์ใน Environment `REVOKED_KEYS` (คั่นด้วยจุลภาค)
- ลูกค้าทำคีย์หาย: ให้เปิดหน้าร้านในเครื่องเดิม (จำคีย์ไว้) หรือส่งสลิปเดิมอีกครั้ง หรือแอดมินใช้ "หาคีย์จากเลขสลิป"

## วิธีติดตั้งของผู้ซื้อ (อยู่ในหน้าดาวน์โหลดด้วย)
- **เซิฟเช่า/BDS**: ลง `.mcaddon` แบบเซิฟ → เปิด Beta APIs → เพิ่ม `@minecraft/server-net` ใน `permissions.json` → รีสตาร์ท
- **โลกธรรมดา**: ลงแบบโลก → เปิดสูตรโกง + ปิด Require Encrypted Websockets →
  เจ้าของโลกเปิดแอป **Windows/Android** เครื่องเดียวกับเกม → ฉันเป็นเจ้าของโลก → **เปิดตัวเชื่อมในเครื่องนี้** → พิมพ์ `/wsserver localhost:19140`
  (คีย์อ่านจากแพ็กในโลกเอง ไม่ต้องพิมพ์ • พิมพ์ `/wsserver wss://...` ตรงไปที่ Render ใช้ไม่ได้ เพราะเกมไม่รองรับการเชื่อมต่อแบบเข้ารหัส)
- **ผู้เล่น**: แอปเดิม (APK/EXE/IPA) ใช้ได้เลย กด ⚙ เปลี่ยนเซิร์ฟเวอร์ → ใส่ลิงก์ HUB • หรือเปิด `<ลิงก์ HUB>/app/`

## ข้อควรรู้
- Render ฟรี: bandwidth ~100GB/เดือน ใช้ร่วมกันทุกเซิฟที่ซื้อ เสียงใช้ ~32KB/วินาที ต่อคนพูดต่อคนฟัง ถ้าขายได้เยอะควรอัปเป็นแพ็กเกจ Starter
- สลิปที่รออนุมัติเก็บในหน่วยความจำ ถ้า Render รีสตาร์ทระหว่างรอ ลูกค้าต้องส่งสลิปใหม่
- เปลี่ยนราคา: Environment `PRICE` (หน้าร้านยังเขียน 69 และ QR ทรูมันนี่ล็อกยอด 69 ไว้ ต้องเปลี่ยนรูป QR ด้วย)
