# Astra Nova Voice — ไมค์ตามระยะสำหรับ Minecraft Bedrock

ใช้รูปแบบเดียวกับ EnviroVoice: **แอดออนลงเซิฟมายคราฟ + ตัวรับส่งเสียงฝากไว้บน Render.com (ฟรี) + แอปให้ผู้เล่น**
เจ้าของเซิฟไม่ต้องรันโปรแกรมอะไรเพิ่มในเครื่องตัวเอง ผู้เล่นเปิดแอปแล้วใส่แค่ชื่อ Xbox

```
[เซิฟมายคราฟ + แอดออน] --ตำแหน่งผู้เล่น--> [Render.com (ฟรี)] <--เสียง--> [แอป Android / iPhone / Windows]
```

## ขั้นที่ 1 — ฝากตัวรับส่งเสียงไว้บน Render (ทำครั้งเดียว ~5 นาที)
1. สมัคร GitHub แล้วสร้าง repository ใหม่ อัปโหลดไฟล์ทั้งหมดใน `AstraNovaVoice-source.zip` ขึ้นไป
2. สมัคร [render.com](https://render.com) ด้วยบัญชี GitHub
3. กด **New → Blueprint** เลือก repository นี้ → Render จะอ่าน `render.yaml` แล้วสร้างให้เอง (โซน Singapore, แพ็กเกจฟรี)
4. รอ Deploy เสร็จ จะได้ลิงก์ เช่น `https://astranova-voice.onrender.com` — แค่นี้พอ ไม่ต้องตั้งรหัสอะไร

## ขั้นที่ 2 — ใส่แอดออนในเซิฟมายคราฟ
1. แก้ไฟล์ `AstraNovaVoice_BP/scripts/config.js` ใน `AstraNovaVoice.mcaddon` (แตกเป็น zip): `serverUrl` = ลิงก์ Render จากขั้นที่ 1
   (ถ้าส่งลิงก์ให้ Claude จะได้แอดออน+แอปที่ใส่ลิงก์ไว้แล้ว ลงได้เลยไม่ต้องแก้อะไร)
2. ใส่แพ็กเข้าโลก แล้ว **เปิด Beta APIs** (Experiments)
3. ถ้าเป็น BDS: เพิ่ม `@minecraft/server-net` ใน `config/default/permissions.json`
   ```json
   { "allowed_modules": ["@minecraft/server-gametest", "@minecraft/server", "@minecraft/server-ui", "@minecraft/server-admin", "@minecraft/server-editor", "@minecraft/server-net"] }
   ```
4. เปิดเซิฟ แอดมินจะเห็นข้อความ "เชื่อมต่อ voice server สำเร็จ"

> แอดออนส่งข้อมูลออกนอกเกมด้วย `@minecraft/server-net` ซึ่งใช้ได้บน **Bedrock Dedicated Server** และโฮสต์ที่ใช้ BDS ส่วน Realms ใช้โมดูลนี้ไม่ได้

## ขั้นที่ 3 — แอปสำหรับผู้เล่น
- **Android**: `AstraNovaVoice-Android.apk` (อนุญาตติดตั้งจากแหล่งอื่น)
- **Windows**: `AstraNovaVoice-Windows.exe` (เปิดใช้ได้เลย ไม่ต้องติดตั้ง) — F8 ปิด/เปิดไมค์, F9 ปิด/เปิดหู ขณะเล่นเกม
- **iPhone / iPad / เครื่องไหนก็ได้ (เว็บ)**: เปิด Safari ไปที่ลิงก์ Render เดียวกัน เช่น `https://astranova-voice.onrender.com` → ใส่ชื่อ Xbox → ใช้ได้เลย
  กด แชร์ → "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอน Astra Nova เปิดเหมือนแอป
  ⚠ เว็บบน iPhone ต้องเปิดหน้าไว้ (สลับแอป/ล็อกจอแล้วไมค์หยุด) จึงเหมาะกับใช้เครื่องหนึ่งคุย อีกเครื่องเล่นเกม (เช่นเล่นบน iPad/PC/คอนโซล คุยบน iPhone)
- **iPhone แบบแอป (IPA, ใช้เบื้องหลังได้)**: build ผ่าน GitHub Actions (ขั้นที่ 4) แล้วติดตั้งด้วย AltStore / Sideloadly / TrollStore

วิธีใช้: เปิดแอป → ใส่ชื่อ Xbox → เข้าเกม → ลิงก์อัตโนมัติ (ครั้งแรกถ้าแอปยังไม่ได้ฝังลิงก์ จะถามที่อยู่เซิฟเสียงหนึ่งครั้ง แล้วจำไว้)

### ใช้งานเบื้องหลังแบบ Discord
- **Android**: เสียงทำงานใน foreground service มีแจ้งเตือนค้าง "Astra Nova Voice" พร้อมปุ่ม *ปิด/เปิดไมค์* และ *ตัดการเชื่อมต่อ* — พับแอปไปเล่นมายคราฟได้เลย
  (ถ้าเครื่องปิดแอปเอง ให้ตั้ง แบตเตอรี่ → Astra Nova Voice → "ไม่จำกัด")
- **iPhone**: ใช้โหมดเสียงเบื้องหลังของ iOS (จะเห็นจุดไมค์สีส้มมุมจอ) เสียงเกมยังดังพร้อมกัน
- **Windows**: ย่อหน้าต่างได้ เสียงไม่หยุด

## ขั้นที่ 4 — Build แอปเอง / ทำ IPA / ฝังลิงก์ให้ผู้เล่นกรอกแค่ชื่อ
1. ใน GitHub repo: **Settings → Secrets and variables → Actions → Variables → New variable**
   ชื่อ `VOICE_SERVER_URL` ค่า = ลิงก์ Render
2. แท็บ **Actions → Build Astra Nova Voice → Run workflow**
3. รอ ~10 นาที ดาวน์โหลด APK / IPA / EXE จากหน้าผลลัพธ์ — แอปชุดนี้ผู้เล่นใส่แค่ชื่อ Xbox อย่างเดียว

## ฟีเจอร์ในเกม
- เสียงตามระยะ: ใกล้ดังเต็ม ไกลค่อยๆ เบา, ซ้าย/ขวาตามทิศที่หัน, คนละมิติไม่ได้ยินกัน
- ไอเท็ม **ไมค์ Astra Nova** (`voice:mic_toggle`): กด = เปิด/ปิดไมค์, ย่อ+กด = เมนู (แจกอัตโนมัติ / คราฟได้)
- **แผงแอดมิน** (`voice:admin_panel`, ต้องเป็น OP หรือ `/tag ชื่อ add voice_admin`):
  ระยะไมค์ 0–100, เปิด/ปิดไมค์ทั้งเซิฟ, เปิด/ปิดหูทั้งเซิฟ, ปิดไมค์/หู/โทรโข่ง รายคน, ประกาศ (แชท+กลางจอ+แอป), แสดง ((♪)) บนหัวคนพูด
- คำสั่ง: `/scriptevent voice:range 30`, `voice:mic on|off`, `voice:hear on|off`, `voice:announce ข้อความ`, `voice:mute|unmute|deaf|undeaf ชื่อ`, `voice:give`, `voice:admin`

## ข้อควรรู้
- ไม่ต้องใช้ SECRET: ระบบเสียงจะจำเซิฟมายคราฟเครื่องแรกที่เชื่อมเข้ามา เครื่องอื่นจะเข้าแทรกไม่ได้ (ถ้าย้ายเซิฟไปเครื่องใหม่ รอ 1 นาทีหลังปิดเครื่องเก่า)
  ถ้าอยากปลอดภัยกว่านี้ ตั้ง Environment `SECRET` บน Render แล้วใส่ค่าเดียวกันใน `config.js`
- ลิงก์ด้วยชื่ออย่างเดียว = ใครรู้ชื่อ Xbox ของคนอื่นก็พิมพ์แอบอ้างได้ (คนเดิมจะถูกเตะออกจากแอป)
  ถ้าต้องการกันตรงนี้ ตั้ง Environment `REQUIRE_CODE=true` บน Render → ครั้งแรกจะมีรหัส 6 หลักเด้งในเกมให้ยืนยัน
- Render ฟรี: ใช้ได้ 750 ชม./เดือน (พอเปิด 24 ชม.) และ bandwidth ~100GB/เดือน เสียงใช้ ~32KB/วินาที ต่อคนพูด ต่อคนฟัง ถ้าคนเยอะมากควรอัปเกรดแพ็กเกจ
- Render ฟรีจะหลับถ้าไม่มีการใช้งาน 15 นาที (ตอนเซิฟมายคราฟปิด) เปิดเซิฟแล้วรอ ~30 วินาทีให้ตื่น
- เสียงสะท้อน: แอปตัดเสียงสะท้อนให้แล้ว (Android/iPhone ใช้โหมดสนทนาของเครื่องแบบ Discord, Windows/เว็บใช้ตัวตัดเสียงสะท้อนของเบราว์เซอร์)
  และมีสวิตช์ **"กันเสียงสะท้อน"** ในแอป: ขณะได้ยินคนอื่น ไมค์จะส่งเฉพาะเมื่อเราพูดดังกว่าเสียงที่ย้อนเข้าไมค์ — ใส่หูฟังยังดีที่สุด
